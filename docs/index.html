Week 8: Number Theory (ทฤษฎีจำนวน)

ศึกษาจำนวนเต็มและสมบัติของมัน มีประโยชน์กับ cryptography และการสุ่มตัวเลขในคอมพิวเตอร์

การหารลงตัว (Divisibility)

a | b ⇔ มีจำนวนเต็ม c ที่ ac = b (a ≠ 0) อ่านว่า a หาร b ลงตัว เทียบได้กับ b/a ∈ ℤ

ตัวอย่าง: 4 | 8 จริง, −3 | 9 จริง, 10 | 0 จริง, 5 ∤ 7

Theorem 1: ถ้า a | b และ a | c แล้ว a | (b + c) · ถ้า a | b แล้ว a | bc ทุก c · ถ้า a | b และ b | c แล้ว a | c

Division Algorithm

a เป็นจำนวนเต็ม d เป็นจำนวนเต็มบวก จะมี q, r ที่ไม่ซ้ำ โดย a = dq + r และ 0 ≤ r < d
q = a div d (ผลหาร), r = a mod d (เศษ)

ตัวอย่าง: 101 = 11·9 + 2 (q = 9, r = 2) และ −13 = 4·(−4) + 3 (q = −4, r = 3) เศษต้องไม่ติดลบเสมอ

Modular Arithmetic และ Congruence

  • เมื่อ a เป็นลบ: a mod d = a − ⌊a/d⌋·d เช่น −17 mod 7 = 4
  • a ≡ b (mod m) ⇔ m | (a − b) ⇔ a mod m = b mod m (อ่านว่า a congruent กับ b modulo m)
  • ตัวอย่าง: 2 ≡ 6 (mod 4) จริง, 24 ≡ 14 (mod 6) ไม่จริง เพราะ 10 หารด้วย 6 ไม่ลงตัว, นาฬิกา 12 ชั่วโมง 14 ≡ 2 (mod 12)
  • สัญลักษณ์ “mod” ใน a ≡ b (mod m) ต่างจาก “mod” ใน a mod m = b (อันหลังเป็นตัวดำเนินการที่ให้ค่าเศษ)
Theorem 4: ถ้า a ≡ b และ c ≡ d (mod m) แล้ว a + c ≡ b + d และ ac ≡ bd (mod m)
ตัวอย่าง mod 5: 7 + 11 = 18 ≡ 3 และ 7·11 = 77 ≡ 2

Modular Operations

  • (a + b) mod m = ((a mod m) + (b mod m)) mod m
  • ab mod m = ((a mod m)(b mod m)) mod m
  • aᵇ mod m = (a mod m)ᵇ mod m แต่ถ้า b ใหญ่ ให้ใช้ divide and conquer
  • b เป็นเลขคู่: aᵇ = (a²)^(b/2) · b เป็นเลขคี่: aᵇ = a·(a²)^((b−1)/2) แล้ว mod ทุกครั้งที่ยกกำลัง
  • ตัวอย่าง: 2⁹⁰ mod 13 = (2⁵⁰ mod 13)(2⁴⁰ mod 13) mod 13 = 4·3 mod 13 = 12

Integer Representations (ฐานเลข)

จำนวนเต็มบวก n เขียนในฐาน b (b > 1) ได้แบบเดียวเท่านั้น: n = aₖbᵏ + … + a₁b + a₀ โดย 0 ≤ aⱼ < b และ aₖ ≠ 0 เขียนเป็น (aₖ…a₁a₀)b
  • ฐานสำคัญ: 2 (binary), 8 (octal), 16 (hex ใช้ A–F แทน 10–15) · ชาว Maya ใช้ฐาน 20 ชาว Babylon ใช้ฐาน 60
  • ตัวอย่างแปลงเป็นฐาน 10: (1 0101 1111)₂ = 351, (11011)₂ = 27, (7016)₈ = 3598, (111)₈ = 73, (E5)₁₆ = 229, (2AE0B)₁₆ = 175,627
  • แปลงจากฐาน 10 ไปฐาน b: หาร n ด้วย b ซ้ำ ๆ เศษแรกคือหลักขวาสุด จนผลหารเป็น 0 แล้วอ่านเศษย้อนกลับ
  • ตัวอย่าง: (12345)₁₀ = (30071)₈, (241)₁₀ = (1111 0001)₂, (177130)₁₀ = (2B3EA)₁₆
  • 1 หลักฐาน 8 = 3 บิต และ 1 หลักฐาน 16 = 4 บิต จึงแปลงระหว่าง binary, octal, hex ได้ง่าย เช่น (11 1110 1011 1100)₂ = (37274)₈ = (3EBC)₁₆

Fast Modular Exponentiation

ใช้ binary expansion ของ n หาค่า b mod m, b² mod m, b⁴ mod m, … แล้วคูณเฉพาะพจน์ที่บิตเป็น 1 (ใช้ O((log m)² log n) bit operations)

x = 1; power = b mod m
for แต่ละบิต aᵢ ของ n (จากขวา): if aᵢ = 1: x = (x·power) mod m; power = (power·power) mod m

ตัวอย่าง: 3⁶⁴⁴ mod 645 = 36 และ 5⁶⁰⁰ mod 13 = 1 (เพราะ 5⁴ ≡ 1 และ 4 | 600) ลองคำนวณเองได้ในส่วน “ลองเล่น”

Week 9: Number Theory

จำนวนเฉพาะ (Primes)

จำนวนเต็ม p > 1 เป็น prime ถ้าตัวประกอบบวกมีแค่ 1 กับ p ถ้าไม่ใช่ prime เรียก composite คือมี a ที่ a | p และ 1 < a < p

ตัวอย่าง: 2, 3, 5, 7, 17 เป็น prime ส่วน 1 ไม่ใช่ prime และ 4, 6, 9, 51 (= 3·17) เป็น composite

Fundamental Theorem of Arithmetic

จำนวนเต็มทุกตัวที่ > 1 เขียนเป็น prime หรือผลคูณของ prime ได้ แบบเดียวเท่านั้น (เรียงจากน้อยไปมาก)

ตัวอย่าง: 100 = 2²·5², 999 = 3³·37, 1024 = 2¹⁰, 641 เป็น prime

การแยกตัวประกอบและ Trial Division

  • ถ้า n เป็น composite จะมี prime ที่หาร n ได้และ ≤ √n เสมอ
  • ดังนั้นแค่ลองหาร n ด้วย prime ที่ไม่เกิน √n ถ้าไม่มีตัวไหนหารลงตัว n เป็น prime
  • ตัวอย่าง: 101 เช็กด้วย 2, 3, 5, 7 (√101 ≈ 10.05) ไม่มีตัวไหนหารลงตัว จึงเป็น prime
  • ตัวอย่างแยกตัวประกอบ: 7007 = 7·7·11·13

Sieve of Eratosthenes

หา prime ทั้งหมดที่ไม่เกิน n โดยไล่ขีดฆ่าตัวคูณของ 2, 3, 5, … (ยกเว้นตัวมันเอง) จนถึง prime ที่ไม่เกิน √n สิ่งที่เหลือคือ prime เช่น prime ไม่เกิน 25 คือ 2, 3, 5, 7, 11, 13, 17, 19, 23

ข้อเท็จจริงน่ารู้

  • Euclid พิสูจน์ว่ามี prime อนันต์ตัว (proof by contradiction): สมมติมี p₁…pₙ จำกัด ให้ Q = p₁p₂…pₙ + 1 ไม่มี pⱼ ตัวไหนหาร Q ลงตัว จึงต้องมี prime ตัวใหม่ ขัดกับสมมติฐาน
  • Mersenne prime อยู่ในรูป 2p − 1 ตัวที่ใหญ่ที่สุดที่รู้ในสไลด์คือ p = 136,279,841 (พบเมื่อ ต.ค. 2024)
  • Prime Number Theorem: จำนวน prime ที่ไม่เกิน x ประมาณ x / ln x

ห.ร.ม. (GCD)

  • gcd(a, b) คือจำนวนเต็มมากสุด d ที่ d | a และ d | b เช่น gcd(24, 36) = 12, gcd(17, 22) = 1
  • a และ b เป็น relatively prime ถ้า gcd = 1
  • Pairwise relatively prime: gcd(aᵢ, aⱼ) = 1 ทุกคู่ เช่น 10, 17, 21 ใช่ แต่ 10, 19, 24 ไม่ใช่ เพราะ gcd(10, 24) = 2
  • ใช้ prime factorisation: gcd เท่ากับผลคูณของ prime โดยใช้ เลขชี้กำลังที่น้อยกว่า เช่น 120 = 2³·3·5 และ 500 = 2²·5³ ได้ gcd = 2²·5 = 20 (วิธีนี้ไม่มีประสิทธิภาพกับเลขใหญ่)

Euclidean Algorithm

Lemma: ถ้า a = bq + r แล้ว gcd(a, b) = gcd(b, r) โดย r = a mod b
ทำซ้ำจนเศษเป็น 0 ตัวหารสุดท้ายคือคำตอบ ใช้ O(log b) ครั้ง

ตัวอย่าง gcd(287, 91): 287 = 91·3 + 14 → 91 = 14·6 + 7 → 14 = 7·2 + 0 ได้ 7

Applications of Congruences

Pseudorandom numbers (linear congruential): xn+1 = (a·xₙ + c) mod m ต้องมี modulus m, multiplier a, increment c, seed x₀ ถ้าใช้ seed เดิมจะได้ลำดับเดิมเสมอ

ตัวอย่าง m = 9, a = 7, c = 4, x₀ = 3: ได้ 3, 7, 5, 3, … (วนซ้ำ)

Check digit ของ UPC (12 หลัก): 3x₁ + x₂ + 3x₃ + x₄ + … + 3x₁₁ + x₁₂ ≡ 0 (mod 10)

ตัวอย่าง 11 หลักแรก 79357343104: ผลรวมที่ยังไม่รวม x₁₂ คือ 98 ต้อง 98 + x₁₂ ≡ 0 (mod 10) ได้ check digit = 2

Cryptography แบบคลาสสิก

  • Caesar cipher: แปลง A–Z เป็น 0–25 แล้วเข้ารหัส f(p) = (p + 3) mod 26 ถอดรหัสด้วย f⁻¹(p) = (p − 3) mod 26
  • Shift cipher: ทั่วไปกว่า ใช้ f(p) = (p + k) mod 26 โดย k คือ key
  • ตัวอย่าง: WINTER IS COMING → ZLQWHU LV FRPLQJ (k = 3) และ FVB ZOHSS UVA WHZZ → YOU SHALL NOT PASS (k = 7)
  • หัวข้อต่อยอดในวิชา Cybersecurity: Affine, Vigenère, Public Key, RSA

Week 10: Relations (ความสัมพันธ์)

นิยามพื้นฐาน

  • Cartesian product A × B = เซตของคู่อันดับ (a, b) โดย a ∈ A, b ∈ B
  • Binary relation จาก A ไป B คือเซตย่อย R ⊆ A × B และ relation บนเซต A คือ R ⊆ A × A
  • Function คือ relation ที่แต่ละ input มี output เดียว ทุก function เป็น relation แต่ relation ไม่ใช่ function ทุกอัน
  • ตัวอย่าง: A = {1,2,3,4}, R = {(a, b) | a หาร b} ได้ (1,1), (1,2), (1,3), (1,4), (2,2), (2,4), (3,3), (4,4)

คุณสมบัติ 4 อย่าง

Equivalence relation และ Equivalence class

Equivalence relation = Reflexive + Symmetric + Transitive (ในตารางบนคือ R₃ และ R₄)
  • Equivalence class ของ a: [a]R = {s | (a, s) ∈ R} สมาชิกใดก็ใช้เป็นตัวแทน (representative) ได้
  • R₃ (a = ±b): classes คือ {0} และ {n, −n} ทุก n > 0
  • Congruence modulo m เป็น equivalence relation: แบ่ง ℤ เป็น class ที่ไม่ซ้อนกัน เหมือนแบ่งพายเป็นชิ้น แต่ละชิ้นคือเศษหนึ่งค่า

ความสำคัญและตัวอย่างใช้งาน

  • Reflexive: primary key ของนักศึกษา เท่ากับตัวเองเสมอ
  • Symmetric: เพื่อนใน Facebook (Instagram follow ไม่ใช่)
  • Antisymmetric: prerequisite ของวิชา ป้องกันวงวน, การเรียงลำดับด้วย ≤
  • Transitive: เส้นทางบิน A→B และ B→C ทำให้ไป A→C ทางอ้อมได้
  • Equivalence: แบ่งกลุ่ม ได้แก่ modular arithmetic, จัดกลุ่มข้อมูลซ้ำใน database, clustering

n-ary Relations และฐานข้อมูล

  • n-ary relation คือเซตย่อยของ A₁ × A₂ × … × Aₙ โดย n คือ degree และ Aᵢ คือ domain
  • n-tuple เท่ากันก็ต่อเมื่อสมาชิกแต่ละตำแหน่งเท่ากัน
  • ตัวอย่าง: (Thai Airways, 924, BKK, MUC, 15:00) เป็น 5-tuple (degree 5)
  • ฐานข้อมูลเชิงสัมพันธ์: table คือ n-ary relation แต่ละแถวเป็น record และ primary key คือ domain ที่ค่าระบุ tuple ได้ไม่ซ้ำ (เช่น ID นักศึกษา)

การแสดง relation

  • Zero-one matrix MR = [mᵢⱼ]: mᵢⱼ = 1 เมื่อ aᵢ สัมพันธ์กับ bⱼ ตัวอย่าง A = {1,2,3}, B = {1,2}, a > b: แถว 1 = (0,0), แถว 2 = (1,0), แถว 3 = (1,1)
  • Digraph: จุด (vertex) กับเส้นมีทิศ (edge หรือ arc) เส้น (a, b) มี a เป็น initial vertex และ b เป็น terminal vertex ส่วน (a, a) คือ loop

Week 11: Graphs Part 1

กราฟและชนิดของกราฟ

Graph G = (V, E) ประกอบด้วยเซตจุด V (ไม่ว่าง) และเซตเส้นเชื่อม E แต่ละเส้นมี 1 หรือ 2 endpoints ถ้า V จำกัดเรียก finite graph ไม่จำกัดเรียก infinite graph

ชนิดลักษณะ
Simple graphไม่มีทิศ เส้นเชื่อมจุดที่ต่างกัน ไม่มีเส้นซ้ำคู่เดิม
Multigraphมีเส้นหลายเส้นเชื่อมสองจุดเดิม (multiplicity m)
Pseudographmultigraph ที่มี loop ได้
Directed graphเส้นเป็นคู่อันดับ (u, v) เริ่มที่ u จบที่ v
Directed multigraphเส้นมีทิศและซ้ำคู่เดิมได้

ตัวอย่างโมเดล: เครือข่ายคอมพิวเตอร์ (simple ถ้าสนใจแค่มี link, multigraph ถ้านับจำนวน link, pseudograph ถ้ามี loop วินิจฉัย), เที่ยวบิน, social network, web links, software dependency, เครือข่ายโปรตีน

ศัพท์ของกราฟไม่มีทิศ

  • Adjacent (neighbors): มีเส้นเชื่อมระหว่างสองจุด เส้นนั้น incident กับสองจุด · N(v) คือ neighborhood
  • deg(v): จำนวนเส้นที่ incident กับ v โดย loop นับ 2
Handshaking Theorem: Σ deg(v) = 2m (m = จำนวนเส้นเชื่อม)
Theorem 2: กราฟไม่มีทิศมีจุดที่ degree เป็นคี่ เป็นจำนวนคู่ เสมอ
  • 10 จุด degree 6 ทุกจุด: 10·6/2 = 30 เส้น
  • 5 จุด degree 3 ทุกจุด: ผลรวม 15 เป็นเลขคี่ เป็นไปไม่ได้
  • degree 2, 2, 2, 3 (ผลรวม 9): เป็นไปไม่ได้ · degree 1, 2, 3, 4 และ 1, 1, 2, 2, 9, 1, 3, 1: เป็น simple graph ไม่ได้ เพราะ degree สูงสุดของ simple graph ที่มี n จุดคือ n − 1
  • 15 คน เพื่อนอย่างน้อยคนละ 3 คน: ทำได้ ขอแค่ผลรวม degree เป็นเลขคู่ (ให้บางคนมีเพื่อน 4 คน)
  • 6 คนจับมือกันครบทุกคู่: C(6, 2) = 15 ครั้ง

กราฟมีทิศ

  • in-degree deg⁻(v) = จำนวนเส้นที่จบที่ v, out-degree deg⁺(v) = จำนวนเส้นที่เริ่มที่ v (loop นับ 1 ทั้งสองฝั่ง)
  • Theorem 3: ผลรวม in-degree = ผลรวม out-degree = จำนวนเส้นเชื่อม

การแสดงกราฟ

  • Adjacency matrix: เมทริกซ์ n × n ที่ช่อง (i, j) = 1 เมื่อ vᵢ กับ vⱼ adjacent
  • Incidence matrix: เมทริกซ์ n × m (จุด × เส้น) ช่อง (i, j) = 1 เมื่อเส้น eⱼ incident กับจุด vᵢ

ใช้โมเดลปัญหาจับคู่ เช่น มอบหมายงานให้พนักงาน (m คน, n งาน, m ≥ n โดยพนักงานหนึ่งคนทำได้หนึ่งงาน)

  • Matching M: เซตย่อยของเส้นเชื่อมที่ไม่มีสองเส้นใช้จุดเดียวกัน
  • Maximum matching: matching ที่มีเส้นมากที่สุด
  • Complete matching จาก V₁ ไป V₂: ทุกจุดใน V₁ เป็น endpoint ของเส้นใน matching (|M| = |V₁|)
Hall’s Marriage Theorem: bipartite graph ที่แบ่งเป็น (V₁, V₂) มี complete matching จาก V₁ ไป V₂ ⇔ |N(A)| ≥ |A| ทุกเซตย่อย A ของ V₁

Path และ Circuit

  • Path ยาว n จาก u ไป v: ลำดับเส้น e₁…eₙ ที่ผ่านลำดับจุด x₀ = u, …, xₙ = v ในกราฟ simple เขียนด้วยลำดับจุดได้
  • Circuit: path ที่เริ่มและจบที่จุดเดียวกัน และยาวมากกว่า 0
  • Simple path/circuit: ไม่ใช้เส้นเดิมซ้ำ
  • ตัวอย่างเชิงสังคม: Six degrees of separation (ทุกคนเชื่อมกันด้วย path ยาวไม่เกิน 5) และ Bacon number (ความยาว path สั้นสุดถึง Kevin Bacon ในกราฟนักแสดง)

Connectivity

  • Connected: มี path ระหว่างทุกคู่จุด ถ้าไม่ใช่เรียก disconnected
  • Connected component: กราฟย่อยที่ connected ใหญ่สุด กราฟที่ไม่ connected มี component ตั้งแต่ 2 ขึ้นไป
  • Cut vertex (articulation point, เช่น router): เอาออกแล้วกราฟแตกเป็นหลายส่วน · Cut edge (bridge, เช่น link): เอาเส้นออกแล้วกราฟแตก
  • Vertex cut (separating set): เซตจุด V′ ที่ทำให้ G − V′ ไม่ connected
Vertex connectivity κ(G): จำนวนจุดน้อยสุดใน vertex cut (สำหรับกราฟไม่ complete) โดย κ(Kₙ) = n − 1, 0 ≤ κ(G) ≤ n − 1 และ κ(G) = 0 ⇔ G disconnected
Edge connectivity λ(G): จำนวนเส้นน้อยสุดใน edge cut (เซตเส้น E′ ที่ G − E′ ไม่ connected) โดย λ(G) = 0 ถ้า G ไม่ connected
โดยทั่วไป κ(G) ≤ λ(G) ≤ ค่า degree ต่ำสุด

การใช้งาน: วัดความทนทานของเครือข่าย (router กับ link) และโครงข่ายถนน ยิ่ง κ, λ สูง ยิ่งเชื่อมต่อแน่น

Week 13: Graphs Part 3

ที่มา: Seven Bridges of Königsberg

ชาวเมืองสงสัยว่าเดินข้ามสะพาน 7 แห่งให้ครบ แห่งละครั้งเดียว แล้วกลับจุดเริ่มได้ไหม ในปี 1736 Euler พิสูจน์ว่า ทำไม่ได้ ซึ่งเป็นจุดกำเนิดของทฤษฎีกราฟ

Euler circuit และ Euler path

  • Euler circuit: simple circuit ที่ผ่าน ทุกเส้นเชื่อม (edge) คนละครั้ง และกลับจุดเริ่ม
  • Euler path: simple path ที่ผ่านทุกเส้นเชื่อมคนละครั้ง ไม่ต้องกลับจุดเริ่ม
Theorem 1: connected multigraph (≥ 2 จุด) มี Euler circuit ⇔ ทุกจุดมี degree เป็นเลขคู่
Theorem 2: มี Euler path แต่ไม่มี Euler circuit ⇔ มีจุด degree คี่ พอดี 2 จุด (path เริ่มและจบที่สองจุดนั้น)

การใช้งาน: เส้นทางถนน สาธารณูปโภค เครือข่ายสื่อสาร การวาดรูปโดยไม่ยกปากกา (เช่น Mohammed’s scimitars) และการเรียงลำดับ DNA

Hamilton circuit และ Hamilton path

  • Hamilton circuit: simple circuit ที่ผ่าน ทุกจุด (vertex) คนละครั้ง
  • Hamilton path: simple path ที่ผ่านทุกจุดคนละครั้ง
  • ชื่อมาจากเกม Icosian puzzle ของ William Rowan Hamilton (1857) บนทรง dodecahedron
  • ต่างจาก Euler ตรงที่ ไม่มีเงื่อนไขง่าย ๆ ที่ใช้ได้ทั้งต้องและพอ ต้องหาโดยลองเดิน
เงื่อนไขพอเพียง (n ≥ 3, simple graph)
Dirac: ทุกจุดมี deg ≥ n/2 ⇒ มี Hamilton circuit
Ore: ทุกคู่จุดที่ไม่ติดกันมี deg(u) + deg(v) ≥ n ⇒ มี Hamilton circuit
ถ้ากราฟไม่เข้าเงื่อนไข ทฤษฎีบทไม่ได้บอกว่า “ไม่มี” ต้องตรวจด้วยวิธีอื่น

Shortest-Path Problems

กราฟที่เส้นเชื่อมมีตัวเลขกำกับเรียก weighted graph shortest path คือเส้นทางระหว่างสองจุดที่ผลรวมน้ำหนักน้อยที่สุด (สไลด์ใช้ตัวอย่างระยะทางเมืองในสหรัฐฯ) ส่วน Traveling Salesman คือหา Hamilton circuit ที่น้ำหนักรวมน้อยสุด

Number Theory

  • หารลงตัว: a | b ⇔ ac = b สำหรับบาง c · a|b และ a|c ⇒ a|(b + c) · a|b ⇒ a|bc · a|b และ b|c ⇒ a|c
  • Division: a = dq + r โดย 0 ≤ r < d · r = a mod d = a − d·⌊a/d⌋ (เศษไม่ติดลบเสมอ)
  • Congruence: a ≡ b (mod m) ⇔ m | (a − b) ⇔ a mod m = b mod m
  • Mod operations: (a + b) mod m = ((a mod m) + (b mod m)) mod m · ab mod m = ((a mod m)(b mod m)) mod m · aᵇ mod m = (a mod m)ᵇ mod m
  • ยกกำลังเร็ว: b คู่: aᵇ = (a²)^(b/2) · b คี่: aᵇ = a·(a²)^((b−1)/2) · หรือแปลง n เป็น binary แล้วคูณ b^(2ʲ) mod m เฉพาะบิตที่เป็น 1
  • Prime: composite n มี prime ≤ √n หารลงตัว · Sieve ขีดฆ่าตัวคูณของ prime ≤ √n · π(x) ≈ x / ln x · Mersenne = 2ᵖ − 1
  • gcd: gcd(a, b) = gcd(b, a mod b) ทำจนเศษเป็น 0 · จาก prime factorisation ใช้ min ของเลขชี้กำลัง · relatively prime ⇔ gcd = 1 · gcd(0, n) = n
  • ฐานเลข: n = aₖbᵏ + … + a₁b + a₀ · ฐาน 10 → ฐาน b: หาร b ซ้ำแล้วอ่านเศษย้อนขึ้น · octal 1 หลัก = 3 บิต · hex 1 หลัก = 4 บิต (A = 10 … F = 15)
  • Shift cipher: f(p) = (p + k) mod 26 · f⁻¹(p) = (p − k) mod 26 · A = 0 … Z = 25 (Caesar: k = 3)
  • Linear congruential: xₙ₊₁ = (a·xₙ + c) mod m
  • UPC check digit: 3x₁ + x₂ + 3x₃ + x₄ + … + 3x₁₁ + x₁₂ ≡ 0 (mod 10)

Relations

  • Reflexive: (a, a) ∈ R ทุก a · Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R · Antisymmetric: (a, b), (b, a) ∈ R ⇒ a = b · Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R
  • Equivalence = Reflexive + Symmetric + Transitive · [a]R = {s | (a, s) ∈ R}
  • เมทริกซ์: reflexive = diagonal เป็น 1 หมด · symmetric: mᵢⱼ = mⱼᵢ · antisymmetric: i ≠ j ห้าม mᵢⱼ = mⱼᵢ = 1
  • Digraph: reflexive = loop ทุกจุด · symmetric = ทุกเส้นมีเส้นย้อน · antisymmetric = ไม่มีลูกศรสองทิศระหว่างจุดต่างกัน · transitive = x→y→z ต้องมี x→z
  • Congruence mod m เป็น equivalence relation · relation แบบ “มีบางอย่างร่วมกัน” มักไม่ transitive

Graphs

  • Handshaking: Σ deg(v) = 2m · จำนวนจุด degree คี่ต้องเป็นเลขคู่ · digraph: Σ deg⁻ = Σ deg⁺ = |E| · simple graph: deg ≤ n − 1
  • จำนวนเส้น: Kₙ = n(n−1)/2 · Cₙ = n · Wₙ = 2n · Qₙ มี 2ⁿ จุด n·2ⁿ⁻¹ เส้น · Kₘ,ₙ = mn
  • Euler circuit: connected และทุกจุด degree คู่ · Euler path (ไม่มี circuit): degree คี่พอดี 2 จุด · Kₙ มี Euler circuit เมื่อ n คี่ · Wₙ ไม่มี
  • Hamilton (เงื่อนไขพอเพียง n ≥ 3): Dirac: ทุกจุด deg ≥ n/2 · Ore: คู่ไม่ติดกัน deg(u) + deg(v) ≥ n · Cₙ (n ≥ 3) มี Hamilton circuit · มี cut vertex/จุด degree 1 ⇒ ไม่มี circuit · ไม่เข้า Dirac/Ore ≠ ไม่มี circuit
  • Connectivity: κ(Kₙ) = n − 1 · κ(G) = 0 ⇔ disconnected · κ(G) ≤ λ(G) ≤ min deg · cut vertex = เอาออกแล้วแตก · bridge = เส้นที่เอาออกแล้วแตก (เส้นในวงปิดไม่ใช่ bridge)
  • Hall: complete matching V₁→V₂ ⇔ |N(A)| ≥ |A| ทุก A ⊆ V₁
  • Path/Circuit: circuit = path ที่จบที่เดิมและยาว > 0 · simple = ไม่ใช้เส้นซ้ำ · ตรวจว่ามีเส้นจริงทุกคู่ติดกันในลำดับ
